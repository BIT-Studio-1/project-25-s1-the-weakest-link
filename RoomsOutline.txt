START ROOM
- Second Entrance -> Hallway4
  Requirement: Tablet

HALLWAY1
- Starting Room -> Start Room
  Requirement: Must NOT have Dagger

- Locked Door -> Tablet Room
  Requirements:
    - Tablet
    - CleanerPresent = false

VINES ROOM
- Side Entrance -> Tablet Room
  Requirement: VinesCut = true

TABLET ROOM
- Locked Door -> Hallway1
  Requirement: Tablet
  Effect: CleanerPresent = true

HALLWAY2
- Glass Door -> End Game
  Requirement: Key

- Down -> Hallway3
  Requirement: LurkerMoved = true

- First Door -> Renovated Room
  Requirement: Tablet

- Side Door -> Spiders Room
  Requirements:
    - Tablet
    - SpiderSacBurst = true

- Fourth Door -> Smashing Room
  Requirements:
    - Tablet
    - LurkerMoved = false

HALLWAY3
- Door -> Eyes Room
  Requirement: Tablet

HALLWAY4
- Forward Door -> Start Room
  Requirement: Tablet

- Side Door -> Key Room
  Requirement: Tablet

- Up -> Hallway3
  Blocked when:
    - VinesCut = true
    - LurkerMoved = false

SMASHING ROOM
- Side Entrance -> Eyes Room
  Requirement: LurkerMoved = true

SPIDERS ROOM
- Main Entrance -> Hallway2
  Requirement: SpiderSacBurst = true

EYES ROOM
- Side Entrance -> Smashing Room
  Requirement: LurkerMoved = false
  Blocked when: LurkerMoved = true

Tablet:
- Access Hallway4
- Access Tablet Room
- Access Renovated Room
- Access Spiders Room
- Access Smashing Room
- Access Eyes Room
- Access Key Room

VinesCut:
- Access Tablet Room through Vines Room

SpiderSacBurst:
- Access and leave Spiders Room

LurkerMoved:
- Access Hallway3
- Access Eyes Room from Smashing Room

Key:
- Open Glass Door (win condition)
